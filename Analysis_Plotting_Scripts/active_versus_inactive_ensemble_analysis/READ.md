This folder contains scripts to run analysis comparing simulation ensembles to active and inactive state protein files.
1) renumber_and_align.py is an auxiliary script that will align and renumber pdb files based sequence overlap. This ensures that the same residues are being compared between known conformational states. This is done in practice, since for the same protein, some residues may be missing or ommitted during experimental structure determination (x-ray, nmr, cryo-em, etc.). In this case, the active state M1 receptor (9UCP.pdb) was post-processed (9UCP_clean.pdb) and used in. this code, along with the inactive state structure (m1.pdb, a post-processed version of 5CXV.pdb). The output, 9UCP_renum_to_m1.pdb, is the active state structure which is used in the subsequent analyses,

2) make_ndx.sh is a short bash script that generates the GROMACS index files for the system, containing the index group in this analyses.  The index files have already been generated for the analysis (index_m1-clemastine.ndx, index_m1-cn045.nex).

3) run_m1_analysis.sh is a bash script that will run the main GROMACS analyses, including torsional angles of Tyr423 (a key conformational microswitch feature residue), distances between the DRY motif residues and Glu360, orthosteric engagement between the drug molecules and key orthosteric residues (Asp105, Tyr106, Tyr381, Tyr404, and Tyr418), and other metrics.  The script currently points to a BASE directory that contains the relevant .tpr and .xtc files for each system.  The choice of index file should be changed accordingly when running the script. The generated output .xvg output files are located in Data/M1_muscarinic_receptor/complexes/DRUG/analysis/replicaX/analysis_active_vs_inactive, for both drugs (clemastine and cn045) and all 3 replica simulations of each system. 

4) All of this generated data can then be used in plot_conformational_state_comparison.py, which will generate .csv and .png files with raw data and plots, respectively. The script currently points to the directories where the input data is stored (the .xvg files from the GROMACS analysis generated from run_m1_analysis.sh).
